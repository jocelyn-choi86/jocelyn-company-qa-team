## 0. 작성 전제

### 0-1. [1단계] 입력 자료 핵심 요약

1. 확정된 입력은 **서비스명(골프예약시스템)과 기능명(로그인)** 두 가지뿐이며, 참고 자료와 대상 사용자/권한은 비어 있다.
2. 따라서 로그인 수단·잠금 기준·세션 시간·2차 인증 여부 등 **모든 수치형 규칙에 근거 자료가 없다.**
3. 서비스 성격(B2B 골프 예약 플랫폼)상 사용자군은 `골프장 관리자 / 대행사 / 최종 고객 / 플랫폼 운영자`로 **가정**하고 정책을 분리 설계했다.
4. 관리자·대행사 계정은 다수 고객 개인정보·예약·정산에 접근하므로 고객 계정보다 **강한 보안 기준을 제안**한다.
5. 계정 열거 공격 방지, 실패 횟수 잠금, 세션 만료, 감사 로그는 수치와 무관하게 **필수 구조 규칙**으로 정의한다.

## 1. 개요

### 1-1. 기능 목적
골프예약시스템의 각 사용자가 본인임을 확인받고, 역할(Role)과 소속 골프장 범위에 맞는 화면·데이터에만 접근하도록 인증 세션을 발급·유지·종료한다.

### 1-2. 배경
- 골프장 관리자·대행사 계정은 티타임 재고, 고객 개인정보(이름·연락처), 예약·결제·정산 데이터에 접근한다. 계정 탈취 시 피해 범위가 크므로 인증 강도와 감사 추적이 필요하다.
- 최종 고객은 예약·취소를 위해 로그인하며, 편의성(자동 로그인)과 보안 사이 균형이 필요하다.
- 구체적 도입 배경(기존 시스템 교체, 보안 감사 지적 등)은 자료 없음. `[기획 확인 필요: Q-00]`

### 1-3. 적용 범위

| 구분 | 항목 |
|---|---|
| **포함** | ID/PW 로그인, 로그인 실패 처리 및 계정 잠금, 세션 발급·유지·만료, 자동 로그인(로그인 유지), 로그아웃, 계정 상태별 로그인 차단(잠금/휴면/정지/탈퇴), 초기·만료 비밀번호 변경 강제, 관리자 2차 인증, 소속 골프장 선택, 로그인 감사 로그, 로그인 관련 알림 |
| **제외** (별도 정책서) | 회원가입(POL-JOIN), 아이디 찾기·비밀번호 재설정(POL-PWD), 계정 생성·초대·권한 부여(POL-ACC), 휴면 전환·해제 상세 절차(POL-DRM), 회원 탈퇴(POL-WDR), 예약 기능 자체(POL-RSV) |
| **경계** | 로그인 화면에서 "아이디 찾기 / 비밀번호 재설정" 링크 노출까지만 본 문서 범위. 이후 플로우는 POL-PWD 범위. |

> 위 별도 정책서 ID는 본 문서에서 제안한 명명이며 실제 문서 존재 여부 확인 필요. `[기획 확인 필요: Q-00]`

## 2. 용어 정의

| 용어 | 정의 |
|---|---|
| 계정 | 로그인 ID 1개에 대응하는 사용자 식별 단위. 1계정 = 1역할을 원칙으로 함 `[기획 확인 필요: Q-12]` |
| 로그인 ID | 사용자가 로그인 시 입력하는 식별값. 형식은 6장 참조 |
| 역할(Role) | 계정이 가지는 권한 묶음. `PLATFORM_ADMIN`, `CLUB_ADMIN`, `AGENCY`, `CUSTOMER` (가정) |
| 소속 골프장 | 관리자·대행사 계정이 접근 가능한 골프장(테넌트). 1개 이상 |
| 관리자 콘솔 | 골프장 관리자·대행사·플랫폼 운영자가 사용하는 B2B 웹 화면 |
| 고객 채널 | 최종 고객이 사용하는 예약 웹/모바일 웹/앱 |
| 로그인 실패 | ID 미존재 또는 비밀번호 불일치로 인증이 거부된 1회의 시도. 입력값 형식 오류(클라이언트 검증 단계 차단)는 실패 횟수에 **포함하지 않음** |
| 연속 실패 횟수 | 마지막 로그인 성공 또는 잠금 해제 이후 누적된 로그인 실패 횟수 |
| 계정 잠금 | 연속 실패 횟수 초과로 일정 시간 로그인이 차단된 상태 |
| 세션 | 로그인 성공 후 발급되는 인증 상태. Access Token + Refresh Token 구조로 가정 `[기획 확인 필요: Q-09]` |
| 유휴 만료 | 마지막 API 요청 이후 일정 시간 요청이 없어 세션이 종료되는 것 |
| 절대 만료 | 활동 여부와 무관하게 로그인 시점부터 일정 시간이 지나 세션이 종료되는 것 |
| 로그인 유지(자동 로그인) | 브라우저/앱 종료 후에도 재로그인 없이 세션을 이어가는 옵션 |
| 2차 인증(MFA) | ID/PW 성공 후 추가로 수행하는 인증(OTP, SMS 인증번호 등) |
| 임시 비밀번호 | 계정 생성·관리자 초기화 시 발급되는 비밀번호. 최초 로그인 시 변경 필수 |
| 감사 로그 | 로그인 시도·성공·실패·잠금·로그아웃 이력을 위변조 불가하게 보관하는 기록 |
