## 0. 작성 전제

### 0-1. [1단계] 입력 자료 핵심 요약

1. 회원은 **공급사(골프장·DMC·여행사)** 와 **판매자(Reseller·Seller)** 로 나뉘고, 구매고객은 Seller의 판매 채널(**TB 또는 개인 홈페이지**)에서 예약한다.
2. 즉시예약은 예약·취소가 바로 확정되고, 확인예약은 예약·취소 모두 **공급사 확인**이 있어야 확정되며 공급사는 취소 요청을 **거절할 수 있다.**
3. 위약 기준은 **업체마다 다르고**, 위약 여부는 **취소 요청 시점**으로 판정한다.
4. 위약 대상 구간에서도 **구매고객은 위약금(수수료)을 내고 취소할 수 있다.**
5. 위약금은 **공급사가 부여·정정**할 수 있고, **판매관리자는 고객 위약금만 정정**할 수 있으며 GDS 위약금은 정정할 수 없다.

## 1. 개요

### 1-1. 기능 목적
GDS에서 유통되는 Tee·Package 상품 예약을 취소할 때, **예약방식·위약구간·취소 주체·판매 채널**에 따라 취소 가능 여부, 공급사 확인 여부, **고객 위약금과 GDS 위약금**, 환불 금액과 환불 처리 흐름을 하나의 기준으로 정한다.

### 1-2. 배경
- GDS는 공급사(골프장·DMC·여행사)의 상품을 판매자(Reseller·Seller)에게 유통하고, Seller는 TB 또는 개인 홈페이지로 구매고객에게 판매한다.
- 따라서 취소 금액은 **판매자 ↔ 구매고객(B2C)** 과 **GDS·공급사 ↔ 판매자(B2B)** 두 단계로 나뉘며, 각 단계의 위약금을 정정할 수 있는 주체가 다르다.

### 1-3. 적용 범위

| 구분 | 항목 |
|---|---|
| **포함** | 취소 가능 주체 판정, 위약구간 판정, 즉시·확인예약 취소 처리, 공급사 취소 확인(승인/거절), 고객 위약금·GDS 위약금 산정 및 부여·정정, 환불 금액 산정, 채널별 환불 처리, 운영방식별 처리 주체, 취소·환불 알림, 감사 로그 |
| **제외** (별도 정책서) | 예약 생성(POL-RSV), 결제(POL-PAY), 판매자·공급사 정산 상세(POL-STL), 부분취소 `[Q-15]`, 노쇼 `[Q-16]`, 일괄 취소 `[Q-17]`, Package 구성품별 개별 취소 `[Q-28]` |

## 2. 용어 정의

### 2-1. 회원 및 주체

| 용어 | 정의 |
|---|---|
| GDS | 공급사의 Tee·Package 상품을 판매자에게 유통하는 본 플랫폼 |
| 공급사 (Provider) | Tee·Package 상품을 공급하는 회원. 종류: **골프장, DMC, 여행사** |
| 판매자 | 공급사로부터 Tee·Package 상품을 공급받아 판매·예약을 수행하는 회원. 종류: **Reseller, Seller** |
| Reseller | GDS를 활용하여 **하위 Seller를 보유**하고 상품을 유통하는 판매자 |
| Seller | GDS를 활용하여 **예약을 수행**하는 판매자. 판매 채널로 **TB** 또는 **개인 홈페이지**를 사용 |
| 하위 Seller | Reseller에 소속된 Seller. Reseller 없이 GDS와 직접 거래하는 Seller와 구분 `[Q-24]` |
| 판매관리자 | 판매자(Reseller 또는 Seller) 소속으로 GDS 어드민을 사용하는 관리자 |
| 공급사 관리자 | 공급사 소속으로 GDS 어드민(공급사 화면)을 사용하는 관리자 |
| GDS 운영자 | GDS를 운영하는 플랫폼 측 관리자. 본 입력에 정의 없음 `[Q-30]` |
| 구매고객 | Seller의 판매 채널(TB/개인 홈페이지)에서 상품을 예약·결제한 최종 고객 |
| TB | Seller의 판매 채널 중 하나. 정의 미확정 `[Q-23]` |
| 개인 홈페이지 | Seller가 자체 운영하는 판매 사이트. GDS와 API로 연동하는 것으로 가정 `[Q-23]` |

### 2-2. 상품 및 예약

| 용어 | 정의 |
|---|---|
| Tee | 티타임 단위 상품 |
| Package | Tee에 숙박·이동 등 다른 구성이 결합된 상품 (구성 정의 `[Q-28]`) |
| GDS 운영방식 | 공급사별 운영 설정. `직접운영` / `위탁운영`. 정의 미확정 `[Q-01]` |
| 즉시예약 | 예약·예약취소 시 **추가 확인 없이 바로** 확정되는 예약 방식 |
| 확인예약 | 예약·예약취소 시 **공급사의 확인이 있어야만** 확정되는 예약 방식. 공급사는 취소 요청을 거절할 수 있음 |

### 2-3. 위약 및 금액

| 용어 | 정의 |
|---|---|
| 위약 기준 | 위약 대상 구간이 시작되는 시점과 구간별 위약 비율. **업체별로 다르게 설정** |
| 위약 기준 시각 | 해당 예약에 적용되는 위약 대상 구간의 시작 시각 |
| 위약 미대상 구간 | 예약 확정 시점부터 위약 기준 시각 **직전**까지. 위약금 0원 |
| 위약 대상 구간 | 위약 기준 시각부터 상품 이용 시작 시각까지. 취소 시 위약금 부과 |
| 취소 요청 시각 | 취소 주체가 취소를 제출해 **GDS 서버가 수신한 시각**. 위약구간 판정 기준(확정). 개인 홈페이지 경유 시 기준 `[Q-31]` |
| **GDS 위약금** | 공급사 위약 기준으로 산정해 **판매자가 GDS(공급사)에 부담**하는 위약금 (B2B). 공급사만 부여·정정 가능 |
| **고객 위약금** | **판매자가 구매고객에게 부과**하는 위약금 (B2C). 기본값은 GDS 위약금과 동일, 판매관리자가 정정 가능 |
| 위약금 차액 | 고객 위약금 − GDS 위약금. 음수면 판매자 부담, 양수면 판매자 수익 `[Q-27]` |
| 고객 환불금액 | 고객 결제금액 − 고객 위약금 |
| 판매자 환급금액 | 판매자의 GDS 공급가 결제금액 − GDS 위약금 `[Q-25]` |
