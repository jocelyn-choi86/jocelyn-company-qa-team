## 0. 작성 전제

### 0-1. [1단계] 입력 자료 핵심 요약

1. 취소·환불 규칙은 **GDS 운영방식(직접/위탁) × 예약방식(즉시/확인) × 위약구간(대상/미대상) × 취소 주체** 조합으로 결정된다.
2. **즉시예약**은 예약·예약취소가 추가 확인 없이 즉시 확정되고, **확인예약**은 예약·예약취소 모두 **공급사 확인이 있어야** 확정된다.
3. **위약 미대상 구간**에서는 공급사·판매관리자·구매고객 3주체 모두 취소할 수 있다.
4. **위약 대상 구간**에서는 공급사·판매관리자만 취소할 수 있고, **구매고객은 직접 취소할 수 없다.**
5. 위약구간의 기준 시각, 위약금 비율, GDS 운영방식이 처리에 미치는 차이는 입력에 없다.

## 1. 개요

### 1-1. 기능 목적
골프예약시스템에서 예약을 취소할 때, **예약방식·위약구간·취소 주체**에 따라 취소 가능 여부, 공급사 확인 필요 여부, 위약금 부과 여부, 환불 금액과 환불 처리 흐름을 하나의 기준으로 정한다.

### 1-2. 배경
- 판매처(GDS)는 공급사(골프장)의 티타임을 판매하며, 공급사마다 예약방식(즉시/확인)과 운영방식(직접/위탁)이 다르다.
- 위약 대상 구간의 고객 셀프 취소를 막아, 위약금 분쟁과 티타임 공실을 공급사·판매관리자가 통제하도록 한다.

### 1-3. 적용 범위

| 구분 | 항목 |
|---|---|
| **포함** | 취소 가능 주체 판정, 위약구간 판정, 즉시예약·확인예약 취소 처리, 공급사 취소 확인(승인/거절), 위약금 산정·면제, 환불 금액 산정, 환불 실행·실패 처리, 운영방식별 처리 주체, 취소·환불 알림, 감사 로그 |
| **제외** (별도 정책서) | 예약 생성(POL-RSV), 결제(POL-PAY), 공급사 정산 상세(POL-STL), 부분취소(인원 감소·일부 티타임 취소) `[Q-15]`, 노쇼 처리 `[Q-16]`, 우천 취소 등 일괄 취소 `[Q-17]` |

## 2. 용어 정의

| 용어 | 정의 |
|---|---|
| 공급사 | 티타임을 제공하는 골프장(또는 골프장 운영 주체) |
| 판매처 / GDS | 공급사의 티타임을 판매하는 본 플랫폼 |
| 판매관리자 | 판매처 어드민에서 예약·취소를 관리하는 판매처 측 관리자 |
| 구매고객 | 티타임을 예약·결제한 최종 고객 |
| GDS 운영방식 | 공급사별 운영 설정. `직접운영` / `위탁운영`. 정의 미확정 `[Q-01]` |
| 즉시예약 | 예약·예약취소 시 **추가 확인 없이 바로** 확정되는 예약 방식 |
| 확인예약 | 예약·예약취소 시 **공급사의 확인이 있어야만** 확정되는 예약 방식 |
| 위약 기준 시각 | 위약 대상 구간이 시작되는 시각. 티타임 시작 시각 기준으로 공급사별 설정 `[Q-02]` |
| 위약 미대상 구간 | 예약 확정 시점부터 위약 기준 시각 **직전**까지. 위약금 없이 취소 가능 |
| 위약 대상 구간 | 위약 기준 시각부터 티타임 시작 시각까지. 취소 시 위약금 부과 대상 |
| 취소 요청 시각 | 취소 주체가 [취소] 처리를 제출해 **서버가 수신한 시각**. 위약구간 판정 기준 `[Q-06]` |
| 취소 확정 | 예약이 `취소완료` 상태가 된 것. 즉시예약은 요청 즉시, 확인예약은 공급사 확인 시점 |
| 위약금 | 위약 대상 구간 취소 시 결제금액에서 차감하는 금액 |
| 위약금 면제 | 위약 대상 구간이지만 취소 사유에 따라 위약금을 0원으로 처리하는 것 |
| 환불금액 | 결제금액 − 위약금 |
